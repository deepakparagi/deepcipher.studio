## 🚀 Getting Started

### Prerequisites

- **Node.js** ≥ 18.0.0
- **npm** or **yarn**

### Installation

```bash
# 1. Clone the repository
git clone https://github.com/deepakparagi/deepcipher.studio.git

# 2. Navigate into the project
cd deepcipher.studio

# 3. Install dependencies
npm install

# 4. Start the development server
npm run dev
```

The app will be available at `http://localhost:3000`
